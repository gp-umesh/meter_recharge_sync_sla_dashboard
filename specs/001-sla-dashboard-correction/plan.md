## Summary

Build a Python SLA correction script that queries three PostgreSQL databases (prepaid engine, MDMS, HES) and computes SLA compliance for prepaid recharge sync operations, applying business rules to determine resolved sync timestamps. Alongside this, configure a Grafana dashboard with panels for real-time SLA monitoring, backed by a materialized `sla_results` table that the script populates.

## Component Design

### `src/sla_engine.py` — Core Business Logic

Implements the timestamp resolution rules from requirements.md:

```python
def resolve_sync_timestamp(commands: list[dict]) -> tuple[datetime | None, str]:
    """
    Returns (resolved_ts, breach_reason).
    breach_reason: 'OK' | 'PARTIAL_SUCCESS' | 'ALL_FAILED'
    """
    successful = [c for c in commands
                  if c['executionStatus'] == 'SUCCESS' and c['executionEndTime']]
    if len(successful) == len(commands) == 5:
        return max(c['executionEndTime'] for c in successful), 'OK'
    elif successful:
        return min(c['executionEndTime'] for c in successful), 'PARTIAL_SUCCESS'
    else:
        return None, 'ALL_FAILED'
```

### `src/queries.py` — Database Queries

Three functions, each connecting to one database:
- `fetch_recharges(date: str, conn) -> list[dict]`
- `fetch_mdms_commands(account_ids: list[str], date: str, conn) -> dict[str, list[dict]]`  
  Returns commands grouped by `account_id`.
- `fetch_hes_executions(execution_ids: list[str], conn) -> dict[str, dict]`  
  Returns HES records keyed by `execution_id`.

### `src/db.py` — Connection Management

Reads connection strings from env vars. Provides context managers for each DB:
```python
with prepaid_conn() as conn: ...
with mdms_conn() as conn: ...
with hes_conn() as conn: ...
```

### `sla_check.py` — Orchestration

```
1. Parse --date, --output, --verbose, --write-db
2. Load .env
3. Fetch recharges for date from db_prepaid_engine
4. Fetch MDMS commands for those account_ids from db_cmd_exec
5. Fetch HES executions for MDMS executionIds from db_hes
6. For each recharge:
   a. Find its 5 MDMS commands
   b. Resolve sync timestamp (sla_engine)
   c. Compute elapsed_seconds, sla_30min_met, sla_60min_met
   d. Extract balance_cmd_status
7. Output breach list (reporter)
8. Print summary to stderr
9. Optionally write to sla_results table (writer)
```

### Grafana Dashboard

Dashboard JSON exported from Grafana and stored in `grafana/dashboard.json`. Panels query `db_prepaid_engine.sla_results` (populated by `sla_check.py --write-db`). See `contracts/grafana-dashboard.md` for full panel specifications.
